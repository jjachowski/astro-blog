# Upgrade - boring stuff

## Astro

Upgrading _astro.js_ itself was quite straightforwad, just running few commands from astro docs. Hardest part was where they said to 'convert' `.npmrc` into `yarnrc.yaml` - it was first time I saw this file format as I'm working with `npm` more.
Upgrade instruction lied a bit, because in the end I left npmrc file as it works well with `nvm use` command and yarnrc file was generated automatically, I have nothing more than node version defined in npmrc so I was fine with empty yarnrc as well.

## Deprecated stuff and Typescript

A lot of time passed sice I changed anything in this project, 2 major versions of _astro_ were released so I had to updated few things. `ViewTransition` was changed to `ClientRouter`, `astro.glob` was removed and replaced by Vite `import.meta.glob` feature. This caused many typescript errors which I professionally solved by using _any_ 🥲.
After all that page is up and running without any visible changes but vercel is not spamming me about all version of node.js - great success!
